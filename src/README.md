
# Sambi-shop - E-commerce Web Application

## Project Description

sambi-shop is a responsive e-commerce web application
built with React. It allows users to browse products,
search by name, filter categories and manage a shopping cart.

## Features

- Product listing using Fake Store API
- Product details
- Search and category filtering
- Add and remove products from cart
- Increase and decrease quantities
- Cart total calculation
- Persistent shopping cart using localStorage
- Responsive design
- Loading, error and empty states

## Technologies

- React
- Vite
- JavaScript
- React Router
- Context API
- CSS3
- Fake Store API
- Vitest
- React Testing Library

## Architecture

- components: reusable UI components
- pages: application pages
- services: API communication
- hooks: custom React hooks
- context: shared cart state
- utils: cart calculations and reducer logic

## Installation

Clone the repository:

git clone YOUR_GITHUB_REPOSITORY_URL:

Enter the project:

cd sambi-shop

Install dependencies:

npm install

Start development server:

npm run dev

Build production version:

npm run build

## Testing

Automated tests cover:

- Cart reducer operations
