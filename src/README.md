# SAMBI-SHOP- An Online Fashion Shopping Website

## About My Project

SAMBI-SHOP is an online shopping website I created to make buying fashion products easier and more convenient. Customers can explore different collections, check product details, choose their preferred options, add products to their wishlist and shopping cart, and place orders.

I wanted to create a simple, attractive and user-friendly website where people can shop for men, women and babies in one place.

## Features

- Browse fashion products for men, women and babies.
- Search and filter products.
- View product details and prices.
- Select available sizes and colours.
- Add and remove favourite products from the wishlist.
- Add products to the shopping cart.
- Check product availability and stock.
- Admin login and dashboard.
- Manage store products and inventory.
- View and manage customer orders.

## Technologies Used

- React.js – Building the website interface.
- JavaScript – Adding functionality and interactions.
- HTML – Structuring the website.
- CSS – Styling and designing the pages.
- Vite – Development server and build tool.
- Supabase – Backend and database services.
- GitHub – Version control and code management.
- Vercel– Deployment configuration.

## How to Install and Run Locally

To run this project on your computer, follow these steps:

## 1. Clone the repository

```bash
git clone GITHUB_REPOSITORY_LINK
```

## 2. Navigate to the project folder
cd sambi-shop
```bash
cd sambi-shop
```

## 3. Install dependencies
npm install
```bash
npm install
```

## 4. Configure environment variables

Create a `.env.local` file and add the required Supabase configuration.

## 5. Start the development server

```bash
npm run dev


## 6. Open the local website

Open the localhost link displayed in your terminal.

## API and Backend

I used Supabase in my project to support the backend connection and database services.

Some of the challenges included:

- Making product information and stock display correctly.

I worked through these challenges by checking my code, testing different solutions and improving the application step by step.
```
